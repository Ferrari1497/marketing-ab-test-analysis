# Marketing A/B Test Analysis

広告表示がユーザーのコンバージョン率に与える効果を、Pythonを用いたA/Bテストで検証しました。

## 分析目的

広告を表示した `ad` 群と、PSA（Public Service Announcement）を表示した `psa` 群のコンバージョン率を比較し、広告表示によってコンバージョン率が統計的に有意に高くなっているかを検証します。

## 使用データ

Kaggle「Marketing A/B Testing」データセットを使用しました。

- データセット：https://www.kaggle.com/datasets/faviovaz/marketing-ab-testing
- データ件数：588,101件
- `ad` 群：564,577人
- `psa` 群：23,524人
- 目的変数：`converted`（コンバージョンの有無）

## 分析方法

Pythonを使用して、以下の分析を行いました。

- データの確認・前処理
- A/Bグループのコンバージョン率比較
- 2群の比率のz検定
- コンバージョン率差の95%信頼区間の算出
- Matplotlibによる可視化

## 主な分析結果

- `ad` 群のコンバージョン率：約2.55%
- `psa` 群のコンバージョン率：約1.79%
- 絶対差：約+0.77ポイント
- 相対的な上昇率：約+42.5%
- 2群の比率のz検定では、p値が有意水準5%を大きく下回った
- 95%信頼区間：約+0.60〜+0.94ポイント

以上から、`ad` 群のコンバージョン率は `psa` 群より統計的に有意に高いと判断しました。

## ビジネス上の提案

ad 群のコンバージョン率は psa 群より統計的に有意に高い結果となりました。
この結果から、広告表示によってコンバージョン率が改善する可能性があると考えられます。

一方、コンバージョン率の絶対差は約0.77ポイントであるため、広告施策を実施・拡大するかどうかは、広告費や商品単価、利益率などを考慮して総合的に判断する必要があります。

今後は広告費や商品単価などのデータを追加し、広告による増分利益や費用対効果を検証します。

## 分析上の限界

- `ad` 群564,577人、`psa` 群23,524人とサンプルサイズに大きな偏りがあるため、実務ではグループの割り当て方法や実験設計を確認する必要があります。
- 本データには広告費、商品単価、利益率などの情報が含まれていないため、広告の費用対効果までは判断できません。
